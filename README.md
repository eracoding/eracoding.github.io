# Ulugbek Shernazarov

Academic and engineering portfolio hosted at [eracoding.github.io](https://eracoding.github.io/).

The homepage is in `index.html`. The stylesheet and appearance toggle are in `stylesheet.css` and `theme.js`. The downloadable public CV is at `data/shernazarov_ulugbek_cv.pdf`.

Open `index.html` in a browser to preview it locally. The site uses plain HTML, CSS, and JavaScript and deploys directly from the GitHub Pages publishing branch without a build step.
